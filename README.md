# Daily Tracker

Phone-first tracker for weight (kg), home workouts, and diet/workout skip days.

- Open `index.html` (or the GitHub Pages URL) on your phone and use "Add to Home Screen".
- Data is stored only on that phone (browser storage). Use **Data → Export backup** regularly.
- **Data → Import** accepts lines pasted from notes, e.g. `31 agosto; 84,6` or `1 September: 82.8 kg`.
